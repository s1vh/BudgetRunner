# Internacionalización

Budget Runner admite estos locales:

- `es-ES`: castellano de España.
- `en-US`: inglés de Estados Unidos y fallback.
- `fr-FR`: francés.
- `de-DE`: alemán.
- `ru-RU`: ruso.
- `zh-CN`: chino simplificado.
- `ja-JP`: japonés.
- `ko-KR`: coreano.

## Comportamiento

En una primera visita, el frontend resuelve `navigator.languages` y usa inglés si no encuentra un idioma compatible. La elección se guarda en `budget-runner-ui-locale`. Al iniciar sesión, el locale persistido en el perfil pasa a ser la fuente de verdad; cambiarlo desde **Ajustes → Región y moneda** actualiza inmediatamente la interfaz y, en modo API, también la base de datos. **Perfil → Contexto regional** muestra el idioma actual y enlaza con esos ajustes.

La interfaz, los errores conocidos, los mensajes del dashboard y del juego, los formatos de fecha/número/moneda y las categorías iniciales usan el locale activo. Las categorías creadas o renombradas por el usuario, los conceptos y notas de transacciones, los nombres de presupuestos y los nombres propios no pasan por el catálogo. Tampoco se traducen Budget Runner, Flux, SynthCoins, Power ni los nombres de las mejoras del Cyberdeck.

Los mensajes de backend que deben mostrarse al usuario viajan como códigos o descriptores (`key`, `params`, `fallback`) y se resuelven en el frontend. Los textos de los iconos de ayuda, la tarjeta de gestión y los pasos del tour usan el mismo catálogo y reaccionan inmediatamente al locale activo. Mantienen literales los mismos nombres propios y términos protegidos: Budget Runner, Flux, SynthCoins, Power, Cyberdeck y los nombres de sus mejoras.

## Prueba local rápida (mock)

Requiere Node.js 22 o superior. Desde la raíz del proyecto, en PowerShell:

```powershell
$env:VITE_DATA_SOURCE='mock'
npm run dev:web
```

1. Abre `http://127.0.0.1:5173`.
2. En **Ajustes → Región y moneda**, selecciona cada uno de los ocho idiomas.
3. Revisa las seis áreas privadas y las pantallas de acceso, registro, privacidad, licencia y 404.
4. Comprueba fechas, moneda, separadores numéricos, gráficas, modales, errores y textos SVG del Cyberdeck.
5. Crea una categoría, una transacción y un presupuesto; cambia de idioma y verifica que sus nombres siguen idénticos.
6. Comprueba que las categorías iniciales sí se traducen y que nombres como Flux, SynthCoins y los módulos no cambian.
7. Abre la ayuda de varias tarjetas con ratón y teclado, cambia de idioma y verifica que el texto usa el locale activo.
8. Ejecuta el tour desde Ajustes, recorre sus secciones y pestañas, abandónalo en un paso intermedio y comprueba que conserva esa página sin crear ni modificar datos financieros.
9. Vuelve a ejecutarlo, complétalo y comprueba que termina en el Dashboard.

Para probar la autodetección desde cero, abre las herramientas del navegador, elimina la clave `budget-runner-ui-locale` de `localStorage`, configura el idioma preferido del navegador y recarga. Un idioma no compatible, por ejemplo italiano, debe abrir la app en inglés. Chino tradicional tampoco se considera chino simplificado y cae al siguiente idioma compatible o a inglés.

## Prueba local con persistencia

```powershell
npm run db:up
npm run db:setup
npm run dev:api
```

En otra terminal:

```powershell
$env:VITE_DATA_SOURCE='api'
npm run dev:web
```

Registra una cuenta con email desde el navegador en uno de los idiomas admitidos, cambia el idioma en Ajustes, cierra sesión y vuelve a entrar. El registro Firebase envía el locale detectado mediante `POST /auth/bootstrap` y la selección posterior debe recuperarse desde PostgreSQL. El OAuth/OIDC heredado también transporta el locale detectado. En el acceso Google de Firebase, una cuenta interna nueva recibe inicialmente el locale por defecto del backend (`en-US`) y el usuario puede cambiarlo después desde Ajustes.

## Verificación automatizada

```powershell
npm test
npm run lint
npm run build
```

Las pruebas de internacionalización comprueban resolución y fallback, que los ocho catálogos estén completos, la conservación de nombres propios y la asignación exclusiva de claves traducibles a categorías del sistema.
